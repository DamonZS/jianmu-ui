# 自检清单 · Checklist

交付前逐项过。任何一项挂 HIGH 就不许说"做完了"。

---

## A · 结构（HIGH）

- [ ] 骨架选型与模块数匹配（≥6 模块用侧栏，4–6 用顶栏，单屏用大屏三栏）
- [ ] 一屏只有一个视觉主区；没有两个同等重量的区域互相竞争
- [ ] 所有卡片落在 3/4/6/8/9/12 列跨度上
- [ ] 同屏卡片间距一致（不混用 12/16/24）
- [ ] 卡片内不嵌套卡片
- [ ] 页面有明确的第一阅读点（一个数字、一个场景或一张表）

## B · 密度（HIGH）

- [ ] 全页只用一档密度（紧凑/标准/舒展）
- [ ] 表格行高 ≥40（常规 ≥48）
- [ ] 卡片内距 ≥16
- [ ] 没有为了"塞更多"而把字号降到 11 以下

## C · 颜色（HIGH）

- [ ] 语义色只有一套约定（涨绿跌红，或按指标类型）
- [ ] 状态色不超过 5 种 + 中性
- [ ] 图表系列色 ≤5，来自 `--chart-*`
- [ ] 品牌色只出现在：主按钮、当前导航项、图表第 1 系列、关键数值强调
- [ ] 没有纯黑 `#000` 和纯白背景以外的纯色大面积铺底
- [ ] 深色界面的底不是 `#000`，是 `#05080F` 级

## D · 字体与数字（HIGH）

- [ ] 所有会变化的数字都有 `font-variant-numeric: tabular-nums`
- [ ] 千分位已加
- [ ] 百分比统一 1–2 位小数
- [ ] 负数用 `−`（U+2212）
- [ ] 中文正文没有用 300 字重（Windows 上发虚）
- [ ] 单位字号比数值小 2 级、颜色降 1 级
- [ ] 没有用 emoji 当图标

## E · 状态（HIGH）

- [ ] 状态用「圆点 + 文字 + 柔和底」的药丸，不是整行色块
- [ ] 同一系统里没有两组同义词（"处理中"/"进行中"只留一个）
- [ ] 未上线功能降不透明度并标注，但仍可点击 → **违规**
- [ ] 每个异步区域都有：加载 / 空 / 错误 三态
- [ ] 空状态不是"暂无数据"四个字，有说明 + 一个主操作

## F · 对比与可达（HIGH）

- [ ] 正文对比度 ≥4.5:1，大号数字 ≥3:1
- [ ] 三级文字（`--ink-3`）没有承载会改变决策的信息
- [ ] 颜色不是唯一编码（状态有文字，图表有图例名）
- [ ] 焦点环存在且可见
- [ ] 可点击区域 ≥32×32
- [ ] `prefers-reduced-motion` 下所有非必要动效关闭
- [ ] 表格有 `<th scope>`，图表有 `aria-label`

## G · 组件细节（MED）

- [ ] 同屏只有一个主按钮
- [ ] 超过 2 个操作时第 3 个起收进 `⋯`
- [ ] 按钮禁用用 `opacity: .45`，没有引入新的灰
- [ ] 分段控件只放 2–4 项
- [ ] 图例在 ≥2 系列时出现
- [ ] 迷你图只做形状，无轴无格
- [ ] 表格空单元格显示 `—`
- [ ] 抽屉宽度 400/480/640 三档之一

## H · 图表（HIGH）

- [ ] Y 轴从 0 起（或标明截断）
- [ ] 网格线只画水平，且极淡
- [ ] 没有双 Y 轴（除非单位不同且量级差 10× 以上）
- [ ] 环形图段数 ≤5
- [ ] 排名条按最大值归一化
- [ ] 悬浮读数吸附最近数据点，不自由跟鼠标
- [ ] 图表容器有固定高度（不靠内容撑开）

## I · 大屏专项（若 C 族）

- [ ] `100vh` 且不滚动
- [ ] 左右栏宽固定，中栏 flex
- [ ] 中栏是场景，没有表格
- [ ] 锚点 ≤6
- [ ] 锚点在 `y < 35%` 时标签翻到下方
- [ ] 告警出现只做一次动画，不循环闪烁
- [ ] 底部 tab 条高度 48，活跃项发光
- [ ] 1920 与 3840 两个宽度都验过

## J · Lumen 专项（若启用）

- [ ] 组件里搜不到 `isNight` / `isDark` / `phase ===`
- [ ] **文字色不是插值出来的**（必须是按背景求解，见 lumen-theme.md 第五节）
- [ ] 全时段对比度已跑脚本验证：4800 点采样，最低 ≥4.5
- [ ] 颜色通道已取整（`Math.round`），没有输出 `rgb(41.39 …)` 这类小数
- [ ] 主题应用**不在 `requestAnimationFrame` 里**（后台标签页会完全不生效）
- [ ] `--surface-alpha` 方向正确：亮底偏实，暗底偏透
- [ ] 拖动时 `data-dragging` 关闭过渡
- [ ] `setPointerCapture` 包了 try/catch
- [ ] `window` 上也挂了 `pointerup`，防止卡在 dragging
- [ ] `←/→/Home/End` 可用
- [ ] `aria-valuenow` 与视觉同步
- [ ] `<meta name="theme-color">` 每次变更同步
- [ ] 图表系列色跟随主题
- [ ] 切到别的标签页再切回，主题已更新

## K · 响应式

- [ ] 1280 / 1440 / 1920 无横向滚动
- [ ] `md` 断点以下侧栏收起为图标
- [ ] 表格在窄屏有横向滚动容器（`overflow-x: auto`），不是压缩列
- [ ] 不做移动版后台（<768 给桌面提示或降级为只读列表）

## L · 代码与资产

- [ ] 颜色全部走变量，无散落 hex（图表配置除外，需集中在一处）
- [ ] 没有引入新的 UI 框架依赖（沿用项目现有栈）
- [ ] 图标来自同一套（lucide 风格），尺寸取 14/16/18/20/24
- [ ] 场景图是 WebP/AVIF，且预压缩
- [ ] 没有实时 WebGL（除非已确认性能预算并做过降级方案）

---

## 一票否决

下面任意一条出现，直接打回：

1. 纯色底 + 白卡 + 无任何空间感/层次，却声称是"玻璃工作台"。
2. KPI 卡里塞装饰性迷你图，数据是随机的。
3. 一屏 6 个以上同等重量的 KPI。
4. 状态只用颜色区分。
5. 深色界面用纯黑底 + 高饱和霓虹。
6. 玻璃层叠玻璃。
7. 数字不用等宽。
8. 未上线功能用正常可点击样式。
9. **主题系统里文字色跟背景一起线性插值**——中途必然灰糊，实测最低 2.82:1。

## 验收话术

交付时不要只说"完成了"。按这个格式：

```
已做：{骨架} + {N 个组件}，{族} 风格，{主题策略}。
验过：1280/1440 无横向滚动；正文对比度 {值}；表格行高 {值}。
未做/未验：{具体项}。
假设：{用到的默认值}。
```

没有验过的不要说验过。
