# 骨架 · Skeleton

四种页面骨架，精确到像素。选型见 `interview.md` Q2.1。

---

## 通用栅格

12 列 / 24px 槽宽，断点：

| 名称 | 宽度 | 页边距 | 内容最大宽 | 侧栏 |
|---|---|---|---|---|
| `xl` | ≥1600 | 32 | 1440 | 208 常开 |
| `lg` | 1280–1599 | 24 | 1280 | 208 常开 |
| `md` | 1024–1279 | 20 | 100% | 64 只留图标 |
| `sm` | 768–1023 | 16 | 100% | 抽屉式 |
| `xs` | <768 | 12 | 100% | 底部 5 项 Tab |

- 卡片可以跨列，但**只能落在 3/4/6/8/9/12 这几个跨度**上。避免 5、7、10 列。
- 同屏卡片行高不一致时，以最高的为准对齐，不要各自居中。

## 骨架 1 · 侧栏工作台

```
┌ rail 64/208 ┬─────────── main ─────────────────────────┐
│ ①  品牌区     │ ②  topbar 56                              │
│              ├───────────────────────────────────────────┤
│ ③  模块列表   │ ④  page-head 72                           │
│              ├───────────────────────────────────────────┤
│              │ ⑤  内容网格  (8 列)  │ ⑥ 侧栏 4 列 320–360  │
│              │                      │                      │
│              │                      │                      │
│ ⑦  底部区     │                                          │
└──────────────┴───────────────────────────────────────────┘
```

### ① 品牌区（高 56）

- 收起态：`logo` 32×32 居中，无文字。
- 展开态：logo 28 + 产品名 15/600，左对齐，左内距 16。
- 过渡：`width var(--dur-2) var(--ease)`。

### ② 顶栏（高 56）

布局 `flex`，四段：`左标题组 | 弹性空白 | 搜索 | 图标组 | 头像`。

| 元素 | 规格 |
|---|---|
| 页面标题 | 15/500，`--ink` |
| 面包屑 | 12/`--ink-3`，分隔符 `/`，与标题同一行，标题前 |
| 搜索框 | 宽 240，高 32，圆角 pill，`--surface-sunken` 底 |
| 图标按钮 | 32×32，圆角 8，hover `--surface-hover` |
| 通知红点 | 8px，`--danger`，右上偏移 `-1px` |
| 头像 | 28 圆形，右内距 16 |

- 顶栏**默认不投阴影**；内容滚动后加 `border-bottom: 1px solid var(--stroke)`（不用阴影，避免与卡片阴影叠加）。

### ③ 模块列表

- 条目高 36，左右内距 12，图标 18 + 文字 13.5/400，间距 10。
- 分组之间 16 空隙，组标题 11/600 全大写 `--ink-3`，左内距 12，下间距 6。
- 当前项：`background: var(--brand-soft); color: var(--brand); font-weight: 500;`
- **不做左侧竖色条**，也不做整条实心品牌色（除 C 族）。
- 展开态可折叠二级项，二级项左内距 40，高 32。
- 组数 ≥5 时，滚动区在品牌区与底部区之间，`overflow-y: auto`，自定义细滚动条（宽 4，`--stroke-strong`）。

### ④ 页面标题区（高 72，`padding: 16 0`）

```
左：H1 20/600 + 副标题 13/--ink-2（可选，行高 1.5，上距 4）
右：次要按钮 + 主按钮（间距 8）
```

- 主按钮：高 36，内距 16，圆角 10，`--brand` 底白字。
- 次要按钮：同尺寸，`--surface` 底 + `--stroke` 边 + `--ink-2` 字。
- 超过 2 个操作时，第 3 个起收进 `⋯` 菜单。

### ⑤ 主内容区

- 列数 8（1200 宽下约 780px），卡片间距 16。
- 卡片内部 `padding: var(--pad-card)`。

### ⑥ 右侧栏（宽 320–360）

- 只在"需要常驻上下文"时启用：待办、活动流、AI 助手、日程、快捷入口。
- 与主区之间**不加分割线**，靠 16 间距。
- 侧栏内卡片可以堆叠，间距 12。

### ⑦ 底部区（高 56–88）

- 收起态：只放一个 32 头像。
- 展开态：升级卡（渐变底，圆角 12，内距 14）+ 用户行（头像 32 + 名字 13 + 邮箱 11 `--ink-3`）。
- 升级卡文案 ≤2 行，一个按钮，高 30 全宽。

### 收起/展开交互

- 收起按钮在品牌区右侧，或侧栏底边。
- 状态存 `localStorage`，默认展开。
- `md` 断点以下强制收起，不读存储值。

## 骨架 2 · 顶栏门户

```
┌──────────────── topbar 64 ─────────────────┐
│ logo  导航tab        搜索  图标  头像       │
├────────────────────────────────────────────┤
│ ② 问候带  (高 96–120，渐变底，KPI 内嵌)      │
├──────────┬──────────────┬──────────────────┤
│ 快捷 3列  │ 趋势/主图 6列  │ 待办/公告 3列     │
├──────────┴──────────────┴──────────────────┤
│ 表格 / 列表（可满宽）                        │
└────────────────────────────────────────────┘
```

### ① 顶栏（高 64）

- logo 左内距 24；导航项间距 4，每项内距 12，高 32。
- **活跃项是深色实心胶囊**：`background: #0F172A; color: #fff; border-radius: 999px`（或品牌色实心）。
- 非活跃项无底无边，hover 时 `--surface-hover`。

### ② 问候带

这是 B 族最强的识别点，三条铁律：

1. **它是一个整条带子**，不是一张卡：`border-radius: 16px`，高 96–120，内距 24。
2. 底色是**一条渐变**：`linear-gradient(100deg, #EEF3FF 0%, #E6F0FF 45%, #F5F8FF 100%)`，右端通常带一张半透明 3D/插画，用 `mask-image: linear-gradient(90deg, transparent, #000)` 让它自然融入。
3. 左侧是问候语（20/600）+ 日期/说明（12/`--ink-3`）；**KPI 放在带子内部的右侧**，每个 KPI 是一个透明块：标签 11 + 数值 24/600 + 环比 11。

- KPI 内嵌时最多 4 个，用竖线（1px，`rgba(0,0,0,.06)`）分隔，高 40。
- 问候语随时间变化：`上午好/下午好/晚上好` + 用户名。**不加 emoji**，除非产品调性明确允许。

### ③ 三栏区

- `快捷入口 3列 | 趋势 6列 | 待办 3列`，间距 16。
- 待办栏常驻右侧，高度与左侧第一屏对齐。

## 骨架 3 · 大屏三栏

```
┌────────────── header 64（标题居中发光）──────────────┐
├ 左栏 320 ┬────────── 中栏 flex ──────────┬ 右栏 320 ┤
│ 统计卡×2  │                             │ 环境卡    │
│ 排行卡    │      3D 场景 + 锚点 + 告警     │ 设备表    │
│ 列表卡    │                             │ 告警流    │
├──────────┴─────────────────────────────┴──────────┤
│ 底部 tab 条 48（视角切换：全局 / 楼栋 / 楼层）        │
└───────────────────────────────────────────────────┘
```

- 整体 `height: 100vh; overflow: hidden`，**大屏不滚动**。
- 左右栏宽固定 320（1920 下）或 360（2560+），中栏 flex 吃掉剩余。
- header 60–72，标题 18–22/600，居中；两侧放时间、天气、用户。标题两侧可加装饰线（1px 渐变，向两端淡出）。
- 左栏顺序固定：**汇总 → 排行 → 明细**。
- 右栏顺序固定：**环境/健康度 → 告警 → 设备/记录**。

### 中栏场景规范

1. 场景图铺满中栏，`object-fit: cover`，`object-position: center`。
2. 场景上叠加四类元素：
   - **区域高亮**：品牌色线框 + `inset 0 0 40px rgba(brand,.25)`，非选中区域轻微降饱和。
   - **锚点**：8px 圆点 + 1px 引线（长 24–40）+ 标签卡。
   - **告警气泡**：图标 16 + 一行文字，红/橙底半透明，出现时 1 次脉冲动画，不循环。
   - **悬浮读数片**：140×88，两行（标签 + 值）。
3. 锚点数量 ≤6。超了改列表，别硬塞。
4. 标签翻转逻辑：锚点 y 坐标 < 35% 时标签向下，否则向上。
5. 底部 tab 条：胶囊底 `rgba(255,255,255,.06)`，活跃项品牌色发光。

### 右侧层区切换轨

竖排，宽 40，居中于右缘，条目 36 高，`border-radius: 999px`；活跃项实心品牌色 + 发光。用于楼层（6F…-2F）、栋号（C 栋/F1–F3/屋顶）。

## 骨架 4 · 单栏列表页

```
┌ page-head 72（标题 + 主操作）┐
├ 工具条 48：搜索 · 筛选×n · 排序 · 视图切换 · 批量操作 ┤
├ 表格（通栏）                                        │
├ 分页器 56                                           │
└────────────────────────────────────────────────────┘
```

- 工具条与表头**不同时 sticky 会有重影**：只让表头 sticky，工具条跟着滚。
- 筛选已选项用胶囊标签行（高 28，可单个 × 移除），单独一行，上距 8。
- 批量操作只在有选中行时淡入，出现在工具条右侧。
- 分页器：`共 N 条 · 每页 [50▾] · ‹ 1 2 3 … 65 › · 跳至 [ ] 页`，右对齐。

## 三种骨架的取舍

| | 侧栏工作台 | 顶栏门户 | 大屏三栏 |
|---|---|---|---|
| 模块数 | ≥6 | 4–6 | 无导航 |
| 内容宽 | 减 208 | 全宽 | 固定三栏 |
| 适用时长 | 长（8h） | 中 | 常驻 |
| 主任务 | 处理 | 概览后进入 | 监视 |
| 信息密度 | 中高 | 中 | 高但远距 |

## 响应式强制规则

1. **不做移动版后台**。B 族在 <768 时给一句"请使用桌面端"，或降级成只读列表。硬塞移动端会让表格变得不可用。
2. A 族可以降级：侧栏变抽屉（左滑出），主区单列，侧栏卡片沉到主区下方。
3. C 族只承诺 1920 与 3840 两个宽度。3840 时整体 `zoom: 1.6` 或等比重设 token，不要靠拉伸。
4. 任何断点下不允许横向滚动条。

## 状态位置

| 状态 | 位置 | 表现 |
|---|---|---|
| 加载 | 卡内 | 骨架屏，形状与最终内容一致，不做转圈 |
| 空 | 卡内居中 | 线稿图 + 一句说明 + 一个主操作 |
| 错误 | 卡内居中 | 图标 + 原因 + `重试` |
| 无权限 | 整页 | 图标 + 说明 + 返回 |
| 部分失败 | 卡内顶部 | 细条警告，说明哪些数据没取到 |
