# 组件 · Components

每个组件给出 **解剖 → 尺寸 → 状态 → 代码骨架 → 反例**。
收录标准：源语料中出现 ≥3 次，或承担不可替代的结构职责。

---

## 1. 卡片（Card）

一切容器的基座。

```
┌─ padding: var(--pad-card) ─────────────────┐
│ header: 标题 15/600 + 右侧操作区（h 28）      │
│         ↕ 12                                 │
│ body                                         │
└──────────────────────────────────────────────┘
```

| 属性 | A 族 | B 族 | C 族 |
|---|---|---|---|
| 背景 | `--surface-glass` | `--surface` | `--surface` |
| 边框 | `1px solid --stroke-glass` | `1px solid --stroke` | `1px solid --stroke` |
| 圆角 | 16 | 12 | 12 |
| 内距 | 20 | 20 | 16 |
| 阴影 | `--shadow-md` | `--shadow-sm` 或无 | `--shadow-md` |
| 模糊 | `blur(var(--blur)) saturate(var(--blur-sat))` | 无 | 无 |

- 卡片**不加 hover 上浮**，除非整张卡可点。可点卡：`cursor:pointer` + hover 时 `border-color: --stroke-strong`，位移不超过 1px。
- 卡片**不嵌套卡片**。需要分组时用分隔线（1px `--stroke`，上下 16 内距）或浅底区块（`--surface-sunken`，圆角 10）。
- 卡片 header 右侧操作区最多 3 个元素：分段控件 / 图标按钮 / `⋯`。

### 反例
- 卡上再叠一张玻璃卡（两层 blur）→ 文字发灰。
- 卡片阴影 + 顶栏阴影同时出现 → 边界糊。
- 每张卡都用不同内距（16/20/24 混用）→ 视觉节奏散。

## 2. KPI 卡

```
┌────────────────────────────────────┐
│ 标签            12/--ink-3      ↗   │  ← 右上角最多一个操作
│                                     │
│ 87,348.00                           │  ← 32/500 tabular-nums
│ 活跃  12/--ink-3                    │  ← 单位/补充，紧贴数值下
│ ↑ 12.5% 较上月     11                 │  ← 三件套：箭头+百分比+对比词
│ ────────────────────────────────    │
│ ▁▂▃▅▆▅▃▂▁  迷你图 h 40             │
└────────────────────────────────────┘
```

### 尺寸

| 元素 | 规格 |
|---|---|
| 卡高 | 无迷你图 96；有迷你图 140 |
| 数值 | 32/500，大屏 40/500 |
| 数值与标签间距 | 8 |
| 数值与单位 | 同一基线，单位 12/`--ink-3`，间距 4 |
| 涨跌行 | 11，上距 8 |
| 迷你图 | 高 40，全宽，无轴无格 |

### 涨跌三件套

```
↑ 12.5% 较上月
│   │      └── 对比词，必填：较上月 / 较昨日 / 较上季度
│   └────────── 百分比，1–2 位小数
└────────────── 箭头：↑ ↓ →（持平用 → 不用 0%）
```

**颜色语义固定，一屏只能一套约定**：

| 指标类型 | 涨= | 跌= |
|---|---|---|
| 营收、产出、转化、满意度 | 绿 | 红 |
| 成本、延迟、告警、失败率 | 红 | 绿 |
| 中性计数（订单数、用户数） | 绿 | 红 |

- 用 `--ok` / `--danger`，不用自定义青绿。
- 颜色同时出现在箭头和百分比文字上；不要给整行加底色。

### 代码骨架

```html
<article class="kpi">
  <div class="kpi-head">
    <span class="kpi-label">运营账号</span>
    <span class="kpi-id">ID · 8674</span>
  </div>
  <div class="kpi-value num">87,348.00</div>
  <div class="kpi-unit">当前活跃</div>
  <div class="kpi-delta up"><span>↑ 12.5%</span><span class="kpi-cmp">较上月</span></div>
  <div class="kpi-spark"><svg viewBox="0 0 120 40" preserveAspectRatio="none">…</svg></div>
</article>
```

```css
.kpi { background: var(--surface); border: 1px solid var(--stroke);
       border-radius: var(--r-card); padding: 16px 18px; }
.kpi-label { font-size: 12px; color: var(--ink-3); }
.kpi-value { margin-top: 8px; font-size: 32px; font-weight: 500; line-height: 1.1;
             font-variant-numeric: tabular-nums; letter-spacing: -.01em; }
.kpi-unit  { margin-top: 2px; font-size: 12px; color: var(--ink-3); }
.kpi-delta { margin-top: 8px; font-size: 11px; display: flex; gap: 6px; align-items: center; }
.kpi-delta.up   { color: var(--ok); }
.kpi-delta.down { color: var(--danger); }
.kpi-cmp   { color: var(--ink-3); }
```

### 反例
- 一屏 6 个 KPI → 读者不知道该看哪个，改 4 个 + 一条趋势。
- 迷你图只是装饰（数据是随机的、不随真实值变）→ 删掉。
- `+12%` 没有对比词 → 读者不知道跟什么比。
- 数值用普通字体 → 定时刷新时整行左右跳动。

## 3. 图表卡

```
┌ 标题 15/600         [今日│近7天│本月]   ⋯ ┐
│                                              │
│                 绘图区 h 180–260             │
│                                              │
│ ● 系列A  ● 系列B          （图例 ≤4）          │
└──────────────────────────────────────────────┘
```

### 规则

1. **时间维度永远在标题行右侧**，不进 body。
2. 分段控件：高 28，内距 10，选中项 `--surface` 底 + `--shadow-sm` + 500 字重，容器 `--surface-sunken` 圆角 8。
3. 图例：只在 ≥2 系列时出现，12px，圆点 8px + 文字，间距 16，靠左；**即使系列色可区分也要有图例**。
4. 悬浮读数：固定在图表右上或跟随十字线，显示日期 + 各系列值，卡片 8 圆角。
5. 绘图区上下留白 16，左右 8（避开 Y 轴标签）。

### 反例
- 分段控件放在图表下方。
- 图例用 5 种以上颜色（人眼分辨不了，改堆叠或"其他"）。
- 双 Y 轴（几乎总是误导，除非单位明确不同且量级差 10× 以上）。

## 4. 数据表

```
┌ 标题 · 共 3,245 条      [搜索] [筛选▾] [排序▾] [导出] ┐  ← toolbar 48
├ 表头 h 40  bg --surface-sunken 12/--ink-3/500 ────────┤
├ 行 h 48  hover --surface-hover ───────────────────────┤
│                                                       │
├ 分页器 h 56                                          ┘
```

### 单元格类型

| 类型 | 结构 |
|---|---|
| 主文本 | 14/`--ink`，单行截断 `text-overflow: ellipsis` |
| 双行 | 主 14 + 次 12/`--ink-3`，行高 1.3，间距 2 |
| 数字 | 右对齐，`tabular-nums`，`--ink` |
| 状态 | 状态药丸（见 6） |
| 人物 | 头像 24 圆 + 名字 13，间距 8 |
| 操作 | 一个文字按钮 + `⋯` |
| 复选 | 18×18，圆角 4，选中 `--brand` |

### 表格细节

- 表头**不加竖线**，只有底部 1px `--stroke`。
- 行间线：数据密时用（1px `--stroke`），疏时不用，靠行高分隔。
- 首列可 sticky（`position: sticky; left: 0`），需要背景色覆盖。
- 列宽：文字列 `min-width: 8em`，数字列固定 120，操作列固定 140。
- 空单元格显示 `—`（em dash），不显示空白。

### 分页器

```
共 3,245 条   [50 条/页▾]   ‹ 1 2 3 … 65 ›   [跳至 __ 页]
```

- 当前页：24×24 圆角 6，`--brand` 底白字。
- 相邻页最多显示 2 个，其余省略号。

### 反例
- 表格里塞图片缩略图 + 3 行文字 + 进度条 + 4 个按钮 → 行高被迫 96，密度全毁。
- 每列都加排序箭头。
- 无数据时显示"暂无数据"四个字，没有任何下一步。

## 5. 待办 / 任务列表

```
[▣] 审批待办            ● 状态      → 
    您有 18 条待办事项    12
    ↑icon 32  ↑标题14     ↑状态/计数  ↑箭头
```

### 规格

| 元素 | 规格 |
|---|---|
| 条目高 | 56（单行）/ 64（双行） |
| 图标块 | 32×32，圆角 8，柔和彩底 |
| 标题 | 14/400 |
| 副文本 | 12/`--ink-3`，单行截断 |
| 右侧 | 计数徽标（20 高，圆角 999）**或**状态点，二选一 |
| 条目间距 | 0（用分隔线）或 4（无分隔线） |

| 类型 | 底 | 图标 |

| 到期 / 告警 | `--danger-soft` | `--danger` |
| 资产 / 盘点 | `--mint-soft` | `--mint` |

同一列表里出现第 6 种颜色就停止上色，统一灰。

## 6. 状态药丸

```
● 进行中
```

```css
.pill {
  display: inline-flex; align-items: center; gap: 6px;
  height: 22px; padding: 0 9px; border-radius: var(--r-pill);
  font-size: 12px; font-weight: 400; white-space: nowrap;
}
.pill::before {
  content: ''; width: 6px; height: 6px; border-radius: 50%;
  background: currentColor;
}
.pill--ok      { color: var(--ok);     background: var(--ok-soft); }
.pill--warn    { color: var(--warn);   background: var(--warn-soft); }
.pill--danger  { color: var(--danger); background: var(--danger-soft); }
.pill--info    { color: var(--info);   background: var(--info-soft); }
.pill--neutral { color: var(--ink-2);  background: var(--surface-sunken); }
```

深色族加发光：`.pill::before { box-shadow: 0 0 8px currentColor; }`

### 固定词表

| 语义 | 颜色 | 词 |
|---|---|---|
| 未开始 | neutral | 草稿 · 待处理 · 待审核 |
| 进行中 | info | 进行中 · 处理中 · 已接单 |
| 成功 | ok | 已完成 · 已通过 · 在线 · 正常 |
| 警告 | warn | 预警 · 待补充 · 部分异常 |
| 失败 | danger | 异常 · 已驳回 · 离线 · 超期 |
| 终止 | neutral（划掉或降透明度） | 已取消 · 已归档 |

**同一系统里不出现两组同义词**（"处理中"和"进行中"只留一个）。

## 7. 步骤条

```
①────────②────────③────────④────────⑤
接入设备   技能授权   探索应用   开始使用   查看结果
 副说明      副说明     副说明     副说明     副说明
```

### 规格

| 元素 | 规格 |
|---|---|
| 序号圆 | 24（紧凑）/ 28（标准） |
| 已完成 | `--brand` 实心底 + 白勾，或品牌色数字 |
| 当前 | `--brand` 实心 + 外圈 3px `--brand-soft` |
| 未到 | 白底 + 1px `--stroke-strong` 边 + `--ink-3` 数字 |
| 连接线 | 高 1，已完成段 `--brand`，未完成段 `--stroke` |
| 标题 | 13/500（当前）/ 400（其余） |
| 副说明 | 11/`--ink-3`，最多 12 字 |

### 三种用法

1. **引导带**：放在页面顶部，一整条 `--surface-sunken` 底，高 80，内距 20。
2. **流程进度**：跟在审批单标题下方，可点击跳转已完成步骤。
3. **空状态引导**：卡片内居中，宽度 70%。

### 反例
- 步骤数 > 5 且每步标题 > 8 字 → 挤成一团，改成纵向。
- 已完成步骤用绿色、当前用蓝色 → 语义混乱，统一品牌色。

## 8. 功能宫格

```
┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐
│  [▣]   │ │  [▣]   │ │  [▣]   │ │  [▣]   │
│ 新建文档 │ │ 新建表格 │ │ 演示文稿 │ │ 文件夹  │
│智能文档创作│ │数据分析  │ │内容创作  │ │整理内容 │
└────────┘ └────────┘ └────────┘ └────────┘
```

### 规格

| 元素 | 规格 |
|---|---|
| 图标块 | 44×44（A 族）/ 36×36（B 族），圆角 12 / 10 |
| 图标块底 | 柔和彩底（同 6 的柔和色板），或用 `linear-gradient(135deg, c1, c2)` 15% 透明 |
| 图标本身 | 单色 20–22px，颜色取底色同系深一档 |
| 名称 | 13/500 |
| 说明 | 11/`--ink-3`，**可选**，只在 A 族用 |
| 间距 | 12 横，16 纵 |
| 项目数 | ≤8 一排；9–15 两排；>15 转分类或列表 |

### 状态

- 可用：正常。
- 待开发：整体 `opacity: .55`，标签改为 `--ink-3` 的"待开发"，**去除 hover 与 cursor**。
- 新增：左上角一个 12px 的小圆点 `--danger`，不写"New"。

### 反例
- 图标用彩色插画 + 单色线稿混排 → 视觉等级不一。
- 同一排 8 个图标 8 种色相 → 颜色失去意义，降到 4–6 个色相循环。

## 9. 三栏主从

```
┌ 树 240 ┬──────── 表/列表 flex ────────┬ 详情 360 ┐
│ 搜索    │ 工具条（搜索/筛选/新建）      │ 标题 + ×  │
│ ▸ 全部  │                              │ 分区1     │
│  ▸ 一级 │ 行：名称 / 类型 / 开关         │ 分区2     │
│   ▸ 二级│                              │ 操作      │
└────────┴──────────────────────────────┴──────────┘
```

### 规格

| 区域 | 宽度 | 说明 |
|---|---|---|
| 左树 | 240 | 可收起为 48 |
| 中表 | flex | 最小 480 |
| 右详情 | 360 | 可关闭，关闭后中表自然变宽 |

- 左树条目高 32，缩进 16/级，最深 3 级。
- 树当前项：`--brand-soft` 底 + 500 字重。
- 右详情头：标题 15/600 + `×` 32；下接分区，分区标题 13/600，间距 20。
- **只有"选择 → 查看/编辑"型任务用三栏**。其余用抽屉。

### 何时用抽屉而非三栏
- 详情字段 ≤12 → 抽屉。
- 需要对照多行数据 → 三栏。
- 详情里有子表格 → 独立页。

## 10. 右侧抽屉

```
┌──────────────────────────────┐
│ 标题 15/600              ×   │  ← header 56
├──────────────────────────────┤
│ 分区标题 13/600              │
│  字段行 h 36                 │
│                              │
│ ─────────────────────────    │
│ 分区标题                     │
├──────────────────────────────┤
│        [取消]  [保存]        │  ← footer 64
└──────────────────────────────┘
```

- 宽 400（默认）/ 480（含表格）/ 640（复杂编辑）。
- 圆角只在内侧两角：`border-radius: 16px 0 0 16px`（从右滑入）。
- 遮罩 `rgba(15,23,42,.32)`，可点击关闭。
- 打开：`transform: translateX(100%) → 0`，`var(--dur-3) var(--ease-out)`。
- 焦点陷阱：打开时焦点移到标题，`Esc` 关闭。
- footer 固定在底部，不随内容滚动。

## 13. 输入框 / 表单

```
标签 13/500
┌──────────────────────────┐
│ 占位     12/--ink-3    ▾ │   高 36，圆角 10
└──────────────────────────┘
帮助文本 11/--ink-3
```

- 默认边 `1px --stroke-strong`，hover 加深，focus `--brand` 1px + 外圈 3px `--brand-soft`。
- 错误：边 `--danger` + 下方 11px 红字说明。
- 标签在**上方**，不做浮动标签（后台表单要快扫）。
- 表单项纵距 16；两列时列距 24。
- 必填星号 `*` 放在标签后，`--danger`，与标签间距 4。

## 17. 空 / 加载 / 错误

### 空状态

```
        [线稿插图 96×96]
        还没有任何项目
        创建第一个项目后，这里会显示进度
              [ 新建项目 ]
```

- 插图用单色线稿或低饱和 3D，尺寸 96–140。
- 标题 14/500，说明 12/`--ink-3`（≤2 行），按钮一个。
- 垂直居中于容器，上下内距 48。

### 加载

- **骨架屏**，形状必须与真实内容一致（同高同宽同圆角）。
- 颜色 `--surface-sunken`，加一层 1.4s 的 `linear-gradient` 扫光（`prefers-reduced-motion` 时静止）。
- 卡内局部加载不遮全卡，只在数据区域换骨架。

### 错误

- 图标 + 原因（12）+ `重试`（次按钮）。
- 网络错误不说"系统异常"，说"数据加载失败，请重试"。

## 18. 提示 / 反馈

| 类型 | 位置 | 时长 | 尺寸 |
|---|---|---|---|
| Toast | 右上，距 24 | 3s | 宽 ≤360，内距 14，圆角 10 |
| 行内提示 | 表单下方 | 持久 | 12px |
| 全局条 | 页面顶部通栏 | 持久，可关 | 高 40 |
| Tooltip | 元素上方 8 | hover 300ms 后 | 12px，深底白字，圆角 6 |

- Toast 同时最多 3 条，垂直堆叠间距 8。
- 成功 Toast 用 `--ok` 图标，失败用 `--danger`，其余 `--info`。
