# 图表与视觉细则 · Charts & Visual

---

## 一、先把问题归类，再选图

| 用户想问的 | 图形 | 不要用 |
|---|---|---|
| 现在多少？ | 大数字 + 单位（KPI 卡） | 任何图 |
| 怎么变的？ | 折线 / 面积 | 饼图、柱状 |
| 谁多谁少？ | 横向条 + 名次 | 饼图 |
| 构成是什么？ | 环形（≤5 段）/ 堆叠条 | 多环嵌套 |
| 达标了吗？ | 半环仪表 / 进度条 | 折线 |
| 分布如何？ | 柱状 / 直方图 | 折线 |
| 何时最忙？ | 格子热图 | 折线 |
| 关系/流向？ | 桑基 | 网络图 |
| 实时波动？ | 迷你柱列 | 仪表盘 |

**一屏只用一种主图**。第二张图要么是不同维度（趋势 + 构成），要么删掉。

## 二、通用绘制规则

### 2.1 轴

- **Y 轴必须从 0 起**。必须截断时（如股价式数据），在轴端画断点符号。
- 网格线只画水平，`1px` 且颜色为 `--stroke` 的一半不透明度（如 `rgba(0,0,0,.045)`）。
- X 轴端点标签左对齐到首点、右对齐到末点，不居中。
- 坐标轴标签 11px，`--ink-3`。
- 单位写在轴标题右上：`单位：万元`，11px。

### 2.2 线与面积

| 属性 | 值 |
|---|---|
| 线宽 | 2（主）/ 1.5（次） |
| 线帽 | `round` |
| 折线拐点 | 默认不画点；hover 时才显示 |
| 面积填充 | 8–12% 不透明度，垂直渐变到 0 |
| 数据点 > 60 | 关闭拐点，线做 `stroke-linejoin: round` |

### 2.3 颜色

- 系列色取 `--chart-1..5`，**按顺序分配**，不挑色。
- 5 个系列是上限。第 6 个起合并成"其他"（`--ink-3`）。
- 语义色（红黄绿）**只用于表达状态**，不用于区分系列。如果系列本身就是状态，那就用语义色，并且图例必须写清楚。
- 深色大屏：线宽加到 2.5，颜色用 `--chart-*` 的亮色档，并在折线下方加 12% 的同色发光。

### 2.4 图例

- 位置：图表下方靠左，或标题行右侧（空间够时）。
- 结构：色块（8×8 圆角 2）或短线（12×2） + 名称，间距 16。
- 可点击切换系列，切换后该项 `opacity: .4` 且加删除线。

### 2.5 悬浮

- 十字虚线（1px `--ink-4`），跟随最近的数据点吸附，不自由跟鼠标。
- 读数卡：白底 + `--shadow-md` + 圆角 8 + 内距 8，第一行日期，后续每行「色块 + 系列名 + 值」。
- 出现 80ms 淡入，消失立即。

## 三、各图表的具体做法

### 3.1 折线图

```
240px
  │      ╭──╮
  │   ╭──╯  ╰─╮
  │ ╭─╯       ╰──
  └────────────────
   05-14   05-17  05-20
```

- 高度 180–260（卡内），大屏 200–280。
- 数据点 ≤30 时可以显示点（r=3，白描边 2）。
- 缺失值：断线，不连线也不补 0。

### 3.2 面积图

- 单系列时才用面积。多系列用线 + 图例。
- 填充：`linear-gradient(180deg, rgba(chart, .18), rgba(chart, 0))`。
- 堆叠面积最多 3 层。

### 3.3 柱状图

- 柱宽 12–24，柱间距为柱宽的 40–60%。
- 圆角只在上端（`rx: 4`），不做全圆角 pill（除非只有 3–5 根）。
- 组内多系列时，柱间距 2，组间距 16。
- 数值不写在柱上（除非 ≤6 根柱），用 Y 轴 + hover。

### 3.4 横向条形（排名）

```
上海  ████████████████  63,828
广州  ██████████████    58,226
北京  ████████████      48,891
```

- 名称列固定宽 80，左对齐；条从名称右侧开始；值在最右，右对齐。
- 条高 12，间距 10，圆角 6。
- 第一名用 `--brand`，其余用 `--brand` 的 55% 透明度。
- 条长按最大值归一化，不是按总和。

### 3.5 环形图

- 环宽 = 外径 × 0.18，外径 120–160。
- 段之间 gap 2px（用 `stroke-dasharray` 留空）。
- 中心：主数值 24/600 + 标签 11/`--ink-3`。
- 段数 ≤5；>5 时把最小几个合成"其他"。
- 图例在右侧竖排，含百分比。

### 3.6 半环仪表

- 只用于 0–100 的达成率。
- 轨道 `--surface-sunken`，进度 `--brand`（达标用 `--ok`）。
- 刻度 5–7 段，刻度线长 4，向外。
- 中心数值 28–36/600 + 单位。

### 3.7 进度条

```
标签 12           87%
██████████████░░░
```

- 高 6（行内）/ 8（卡片内）。
- 底 `--surface-sunken`，填充 `--brand`，圆角 pill。
- 标签在左、值在右，条在下一行全宽。

### 3.8 迷你图（sparkline）

- 只做形状：无轴、无网格、无标签、无点。
- 高 28–40。
- 颜色跟随趋势语义（涨绿跌红）或统一 `--chart-1`，**一屏内二选一**。
- 底部可加 1px 的基线（`--stroke`），也可以不加。

### 3.9 热图

- 格子 20–28，圆角 4，间距 3。
- 5 档色阶，从 `--surface-sunken` 到 `--brand`。
- 行列标签 11px。
- hover 显示"周X HH:00 · N 次"。

### 3.10 桑基

- 只在强关系场景用（人员调动、资金流向、转化路径）。
- 节点宽 8–12，节点间距 20。
- 连线 20% 不透明度，hover 时该路径升到 60%，其余降到 8%。
- 节点标签在两端外侧。

### 3.11 实时脉冲柱

- 用于监控大屏的"最近 N 秒"。
- 40–60 根细柱，宽 2–3，间距 1。
- 新数据从右侧推入，旧数据淡出（`opacity` 渐变）。
- 高度取对数或归一化，否则尖峰压平其余。

## 四、KPI 的数字排版

数值是后台界面里出现最多的"视觉主体"，单独规定：

```css
.value {
  font-variant-numeric: tabular-nums;
  font-feature-settings: 'tnum' 1;
  letter-spacing: -.01em;   /* 大字号收紧一点 */
}
```

| 场景 | 字号 | 字重 |
|---|---|---|
| 卡片 KPI | 32 | 500 |
| 大屏 KPI | 40 | 500 |
| 详情页标题数字 | 24 | 500 |
| 表格内数字 | 14 | 400 |
| 展示型（Lumen 等） | 40–56 | 300 |

- 千分位一律加（`87,348.00`，不是 `87348`）。
- 百分比：1 位小数为主（`99.98%`），2 位仅在需要精度时（`0.05%`）。
- 金额：整数部分千分位，小数统一 2 位，货币符号放前面；币种不同时加后缀。
- 单位与数值之间不加空格（`3,178 kg` 里的空格保留给人读，图表轴用 `3178kg` 或不带单位）。
- **负数用减号 `−`（U+2212），不用连字符。**

## 五、图标

- 统一 lucide 风格：24 网格、2px 描边、`stroke-linecap: round`。
- 尺寸档：14（行内）/ 16（按钮）/ 18（导航）/ 20（宫格）/ 24（空状态图）。
- 颜色继承 `currentColor`，**不单独给图标上色**（除了功能宫格里的柔和块）。
- 品牌 logo 除外：logo 可以是彩色的，但只出现一次。
- 不用 emoji 当图标。用户头像除外（源语料里那些是占位头像）。

## 六、插图

三种可用：
1. **等距 3D 小场景**（A 族宫格、空状态）——单色系或双色，45° 等距，柔和投影。
2. **线稿**（空状态、错误）——1.5px 描边，`--ink-4`。
3. **写实渲染图**（C 族场景、A 族首屏）——静态 WebP，预先压好。

禁止：图库照片、多风格混排、带文字的插图。

## 七、密度与呼吸

| 元素 | 紧凑 | 标准 | 舒展 |
|---|---|---|---|
| 卡片内距 | 16 | 20 | 24 |
| 卡片间距 | 12 | 16 | 24 |
| 表格行高 | 40 | 48 | 56 |
| 区块间距 | 16 | 24 | 32 |
| 页面顶部到内容 | 16 | 24 | 40 |

- **同一页只用一个密度档**。
- 舒展档用于 A 族首屏与营销页；紧凑档用于 B 族数据页；大屏用 `--density: .92`。
- 留白优先加在**区块之间**，不是卡片内部。卡片内部挤压会让信息难扫。

## 八、深浅两套的差异清单

| 项 | 浅色 | 深色 |
|---|---|---|
| 层次靠 | 阴影 | 描边 + 内发光 |
| 卡片底 | 实白 / 半透白 | 近黑半透明 |
| 分隔线 | `#EAEEF5` | `rgba(120,170,255,.14)` |
| 强调 | 实色背景 | 发光 + 描边 |
| 图表网格 | `rgba(0,0,0,.045)` | `rgba(120,170,255,.10)` |
| 面积填充 | 12% | 18%（深底上要更高才看得见） |
| 文字对比 | `#0F172A` on `#FFF` ≈ 15:1 | `#E8F1FF` on `#05080F` ≈ 16:1 |
| 次级文字 | `#475467`（≈ 7.6:1） | `#93A7C4`（≈ 8.1:1） |
| 三级文字 | `#98A2B3`（≈ 3.1:1，**仅限非关键信息**） | `#5A6E8C`（≈ 3.4:1） |

三级文字不要放会改变决策的内容。

## 九、可访问性底线

1. 正文对比度 ≥ 4.5:1；≥24px 的数字可 3:1。
2. **颜色不作为唯一编码**：状态既有色又有文字，图表系列既有色又有图例名。
3. 焦点环 2px `--brand`，偏移 2px，永不移除。
4. 可点击区域 ≥ 32×32（触屏 ≥ 44）。
5. `prefers-reduced-motion` 下关闭所有非必要动效。
6. 表格 `<th scope>`、图表容器 `role="img"` + `aria-label` 摘要。
7. 不用纯红/纯绿作唯一区分（红绿色盲）；状态的第二编码是图标或文字。
