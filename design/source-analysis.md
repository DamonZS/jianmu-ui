## 0. 语料分族

| 族 | 代表 | 视觉锚点 | 适用 |
|---|---|---|---|
| **A · 玻璃工作台** | Payrix、Flux、AI 助手、通义效率、CueMe、星耀、客户端仪表板、Clerio、inShield | 柔光渐变底 + 3D 主视觉 + 半透明白卡 + 大圆角 | AI 产品、个人工作台、轻量 SaaS |
| **B · 管理台** | ERP ×4、企业门户 ×3、Global ×3、财务工作台、商品中心、集采平台、语义规则中心、MOM/CIM、RoutaX、SkyLift | 实色白卡 + 紧凑网格 + 顶栏/侧栏常驻 + 表格 | 后台管理、审批、运营 |
| **C · 监控大屏** | 时空智控、IoT 机房、水文一张图、智慧工厂、AGV 仓储、储能、换电、物流大屏 | 深底 + 发光描边 + 等距/写实 3D 场景 + 悬浮锚点 | 大屏、指挥中心、产线监控 |
| **特例 · Lumen** | 4 帧：Night 00:43 / Golden hour 07:01 / High noon 12:00 | 拖动顶部圆窗里的太阳 → 整页明暗与色温连续变化 | 需要"环境即主题"的展示型产品 |

三族共享同一套布局语法，差别只在 **光**、**密度**、**背景材质**。跨族复用组件时只换 token，不改结构。

## 1. 五条结论

1. **背景永远是一个"场景"，不是一块颜色。**
   每张好图背后都有东西：3D 车/机柜/楼宇、等距厂区、渐变光斑、人物插画。卡片浮在场景之上，玻璃只负责让场景透出来。纯色底 + 白卡是 B 族的底线，不是 A 族和 C 族的做法。

2. **一张卡只回答一个问题。**
   是"现在多少"（KPI）、"怎么变的"（趋势）、还是"有哪些"（清单）。看到的失败案例几乎都违反这条——单张 KPI 卡里塞了迷你柱图 + 环比 + 说明文 + 装饰图标。

3. **密度分三层，不要混。**
   大屏 = 左中右三栏，左右栏是读数，中间是场景；工作台 = 主区 + 320–360px 侧栏；列表页 = 单栏贯穿 + 顶部工具条。同一屏不要出现两种密度。

4. **状态只用一个色相 + 一个形状。**
   圆点 + 文字（`● 进行中`），不要整行色块。颜色只出现在：状态点、数值变化、图表系列、唯一主按钮。

5. **主题是一组变量，不是一个分支。**
   Lumen 的做法是唯一正确的做法：一个连续状态变量（太阳角度）→ 派生整套 CSS 变量。组件不认识"白天/黑夜"，只认识 `--surface`。

## 2. Design Tokens

### 2.1 颜色 · 浅色（A/B 族）

```css
--bg:            #F5F7FB;
--bg-blob-1:     #E3EDFF;   /* 左上柔光斑，radial-gradient，不透明度 .5-.7 */
--bg-blob-2:     #FFF2E4;   /* 右下暖斑，A 族才加 */
--surface:       #FFFFFF;
--surface-glass: rgba(255,255,255,.66);
--surface-sunken:#F0F3F8;   /* 表头、分段控件底 */
--stroke:        #EAEEF5;
--stroke-strong: #DDE3ED;
--ink:           #0F172A;
--ink-2:         #475467;
--ink-3:         #98A2B3;
--brand:         #2563EB;
--brand-soft:    #E8F0FF;
--ok:            #12B76A;
--warn:          #F79009;
--danger:        #F04438;
--violet:        #7A5AF8;
--mint:          #2ED3B7;
```

### 2.2 颜色 · 深色（C 族）

```css
--bg:            #05080F;
--surface:       rgba(13,20,34,.72);   /* 叠在 3D 场景上 */
--surface-solid: #0A1220;
--stroke:        rgba(120,170,255,.14);
--stroke-glow:   rgba(56,189,248,.35); /* 只给"当前"状态的卡 */
--ink:           #E8F1FF;
--ink-2:         #93A7C4;
--ink-3:         #5A6E8C;
--brand:         #38BDF8;
--brand-2:       #2563EB;
--ok:            #34D399;
--warn:          #FF8A3D;
--danger:        #FF5A5F;
```

深色大屏的规律：**底色近黑但不纯黑**，卡片靠 `1px 半透明蓝边 + 内发光` 而不是阴影区分层次；霓虹只用在品牌色和告警色，不使用第三种。

### 2.3 圆角 / 间距 / 高度

```css
--r-xs: 8px;  --r-sm: 10px; --r-md: 12px;
--r-lg: 16px; --r-xl: 20px; --r-2xl: 24px; --r-pill: 999px;
```

- 卡内小件（图标块、状态药丸）：8–10
- 卡片：12（B 族） / 16–20（A 族）
- 外层容器、抽屉、弹窗：20–24
- 4pt 栅格：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40
- 页边距 24（1280 宽）；卡片内边距 20；卡片间距 16
- 顶栏 56（紧凑）/ 64；侧栏 64 收起 / 208 展开；侧栏条目 36 高

### 2.4 阴影 / 玻璃

```css
/* 浅色 */
--shadow-sm: 0 1px 2px rgba(16,24,40,.04);
--shadow-md: 0 1px 2px rgba(16,24,40,.04), 0 12px 32px -12px rgba(16,24,40,.10);
/* 深色：用描边+外扩暗影代替环境阴影 */
--shadow-dark: 0 0 0 1px rgba(56,189,248,.10), 0 24px 60px -24px rgba(0,0,0,.80);
```

玻璃只给**浮在场景上的**控件：顶栏、侧栏、悬浮读数、抽屉。`backdrop-filter: blur(12px) saturate(160%)`。
大屏场景卡不用 backdrop-filter——深色页面上它只增加 GPU 成本，视觉收益接近零。

### 2.5 字体与数字

- 中文正文 14/1.6，正文次级 13，标注 12，微标 11
- 页面标题 20–24；区块标题 15–16/600
- KPI 数值 28–40，字重 500–600（Lumen 用 300 的极细大数字，属展示型特例）
- **所有数字 `font-variant-numeric: tabular-nums`**，避免刷新时跳动
- 单位比数值小 2–3 级、降一级灰，紧跟数值不带空格（`87,348.00`、`99.23%`、`3,178 kg`）
- 千分位一律加；百分比保留 1–2 位小数；时间用 `2025-05-20 10:30` 而非中文日期

## 3. 三种骨架

### 3.1 侧栏工作台（A 族主用，B 族通用）

```
┌─rail(64/208)─┬────────── main ──────────┐
│ logo         │ topbar 56: 标题·搜索·通知·头像 │
│ ───────────  ├──────────────────────────┤
│ ● 首页        │ 页面标题 + 右侧主操作        │
│ ○ 我的文件    ├──────────────────────────┤
│ ○ 智能工具    │ 主区 (8col|9col)  │ 侧栏 4col|3col │
│ ○ 知识库      │                   │ 320–360px      │
│ ...          │                   │                │
│ ───────────  │                   │                │
│ 升级卡/用户   │                   │                │
└──────────────┴───────────────────┴────────────────┘
```

- 侧栏收起 64px 只留图标；展开 208px。当前项用 `--brand-soft` 底 + 品牌色图标，**不做左侧色条**。
- 侧栏底部固定：升级卡（渐变）+ 用户行。这是 A 族的标配，B 族可省。
- 侧栏可分组（基础/操作/数据/管理），组标题 11px 全大写灰字。

### 3.2 顶栏门户（B 族）

```
┌──── topbar 64：logo │ 主导航(胶囊tab) │ 搜索 │ 图标 │ 头像 ────┐
├──────────────────────────────────────────────────────────┤
│ 问候条 / 渐变 hero band（问候 + 4–5 个 KPI 内嵌）              │
├──────────────┬──────────────┬────────────────────────────┤
│ 快捷入口 3col │ 趋势 6col     │ 待办/公告 3col              │
└──────────────┴──────────────┴────────────────────────────┘
```

- 主导航活跃项是**深色实心胶囊**（黑或品牌色），不是下划线。
- 问候条是一整条淡蓝渐变带，把 KPI 放在带子内部——这是 B 族最强的识别点，见 ERP 工作台、财务工作台、供电所工作台。

### 3.3 大屏三栏（C 族）

```
┌ header 64：标题(居中发光) │ 时间/天气/用户 ───────────────┐
├ 左栏 300–360 ┬────── 中栏 flex ──────┬ 右栏 300–360 ┤
│ 统计/排行     │  3D 场景 + 悬浮锚点     │ 环境/告警     │
│ 列表          │  底部 tab 切换视角      │ 设备表        │
└──────────────┴────────────────────────┴──────────────┘
```

- 左右栏卡宽固定，中栏吃掉剩余空间；**中栏永远是场景，不放表格**。
- 场景上叠加：区域高亮（绿/橙发光块）、锚点标签（圆点 + 引线 + 名称/编号卡）、告警气泡。
- 右侧竖排「楼层/层区」切换轨（机房、C 栋、厂区都用了），当前项高亮成胶囊。

## 4. 组件模式库

每个组件给出：**结构 → 规则**。截图里出现 ≥3 次才收录。

### 4.1 KPI 卡

```
┌──────────────────────────────┐
│ 标签 12/--ink-3        ↗ 或 ⋯ │
│ 数值 32–36/600/tabular-nums   │
│ 单位 12/--ink-3               │
│ ↑12.5% 较上月   （蓝/绿=好，红=差）│
│ ── 40–56px 迷你图（可选）──────│
└──────────────────────────────┘
```

- 涨跌用「箭头 + 百分比 + 对比词」三件套，缺一不可。只写 `+12%` 不知道跟谁比。
- 涨跌色语义固定：营收/效率类上涨=绿，成本/延迟/告警类上涨=红。同一屏不要两种约定。
- 迷你图只画形状，不画坐标轴、不画网格。它是"趋势暗示"，不是图。
- 一屏 4 个为上限，第 5 个请放进趋势区。

### 4.2 图表卡

```
┌ 标题 15/600    [今日|近7天|本月]  ⋯  ┐
│                                      │
│            绘图区                     │
│                                      │
│ 图例（系列 ≤4，超出转"其他"）           │
└──────────────────────────────────────┘
```

- 时间维度用分段控件，永远放在标题右侧、同一行。
- 系列上限 4；第 5 条开始合并。线宽 1.5–2，面积填充 8–12% 不透明。
- 只在 X/Y 轴画极浅网格线（`--stroke` 一半），或完全不画。
- 激活态给一个悬浮读数卡（日期 + 各系列值），不要 tooltip 跟随鼠标。
- Y 轴从 0 起；如果必须截断，在轴端标注断点。

### 4.3 数据表

```
┌ 标题 · 计数  [搜索] [筛选▾] [排序▾] [导出] ┐
│ 表头 12/--ink-3/sunken 底                  │
│ 行 48–56 高，hover 行底 --surface-sunken    │
│ 单元格：主值 --ink，次要 --ink-3，右对齐数字  │
│ 分页器：共 N 条 · 每页 · ‹ 1 2 3 ›          │
└────────────────────────────────────────────┘
```

- 行内不发散边框，只保留表头下一条 + 行间极淡线（或不画线，用行高分隔）。
- 第一列常是「图标/缩略图 + 主名称 + 次级说明」两行堆叠。
- 状态列统一用状态药丸（4.6）。
- 行操作：`⋯` 收进菜单；只把 1 个高频操作放外面（详情/处理）。

### 4.4 待办 / 任务列表

```
[icon 32 圆角块] 标题 14          ● 状态  →
                 副标题 12 灰
```

- 左侧图标块按类型上色（审批=蓝、消息=橙、任务=紫、到期=红），这是全语料最稳定的编码。
- 右侧是计数徽标、状态点或箭头，**只放一个**。
- 分组标题带"全部待办 ›"右对齐链接。

### 4.5 进度 / 仪表

- **环形**：中心放主数值，弧上放 2–3 个 tick 标签；不写百分比在图外。
- **半环仪表**：只用于 0–100 的达成率；刻度 5–7 段。
- **横向进度条**：高 6–8，圆角 pill，底色 `--surface-sunken`；标签在左，数值在右。
- 何时用哪个：单指标占比→环形；区间达标→半环；多条并列→横条；时间序列→线。

### 4.6 状态药丸

```
● 进行中      ● 已完成     ● 预警     ● 草稿
```

- 结构固定：8px 圆点 + 12px 文字 + 半透明同色底 + 999 圆角，高 22–24。
- 词表固定，不要同义混用：`草稿 / 待处理 / 进行中 / 已完成 / 已取消 / 预警 / 异常`。
- 深色主题下圆点加 `box-shadow: 0 0 8px currentColor`。

### 4.7 步骤条 / 快捷 N 步

```
① 接入设备 ── ② 技能授权 ── ③ 探索应用
   副说明        副说明        副说明
```

- 序号圆 24–28，当前及已完成用品牌色实心，未到用描边。
- 连线上加箭头；整体放在一条浅色底带里（`--surface-sunken` 或渐变条）。
- 出现在三处：顶栏下方引导带、空状态引导、流程审批进度。

### 4.8 功能宫格

```
[40–48 图标块，柔和渐变底] [40–48] [40–48] ...
    名称 12                      ...
    状态 11（已上线/待开发）
```

- 图标块底色用协调的粉彩对（蓝/绿/紫/橙/青），同一屏不超过 6 个色相。
- 图标本身单色描边（lucide 风格），不要彩色插画混排。
- 项目数 ≤8 用一排，9–15 用两排，超过转列表或分类页。
- 未上线项整体降不透明度到 55% 并标 `待开发`，不要用灰色图标假装。

### 4.9 三栏主从（规则中心 / 权限 / 知识库）

```
┌ 树 240 ┬──── 表 flex ────┬ 详情 360 ┐
│ 分类    │ 搜索 + 筛选 + 新建 │ 关闭 ×    │
│ ▸ 一级  │ 行：名称/类型/开关  │ 基本信息   │
│  ▸ 二级 │                    │ 配置项     │
└────────┴────────────────────┴──────────┘
```

- 只有"选择 → 查看/编辑"这一类任务才用三栏；其余用抽屉。
- 右侧详情用 360，不和中间表抢宽度；打开时中间表不压缩，而是浮层覆盖。

### 4.10 右侧抽屉

- 宽 360–420，圆角 16 只在内侧两角，外侧贴边。
- 头：标题 + `×`；体：分区（分区标题 13/600 + 间距 20）；底：1–2 个操作按钮。
- 抽屉是 B 族处理"详情/编辑"的默认答案，不要新开页。

### 4.11 场景浮层组件（C 族 & A 族）

**锚点标签**
```
        ╭──────────╮
        │ 储料罐     │   ← 深底半透明卡，16 圆角
        │ N2037    │
        ╰────┬─────╯
             │ 1px 引线 + 端点圆环
             ●  ← 落在 3D 物体的点上
```
- 标签朝向要避让：上方空间不够就翻到下方。数量 ≤6，多了改列表。

**悬浮读数片**
- 尺寸约 140×88，贴在场景上，玻璃底 + 1px 高光边；只放 2 行（标签 + 值）。

**区域高亮**
- 选中区域用品牌色线框 + 内发光（`box-shadow: inset 0 0 40px rgba(brand,.25)`），其余部分轻微降饱和。

### 4.12 AI 助手侧栏

```
┌ 助手标题 · 新会话 ⋯ ┐
│ 用户气泡（右，品牌色）  │
│ 助手气泡（左，浅底）    │
│ 结果卡片：图/表/引用    │
├──────────────────────┤
│ 输入框  [工具开关][发送] │
└──────────────────────┘
```

- 助手回复里的结构化结果用**小卡片**承载（缩略图 + 名称 + 2 个指标），不要整段文字。
- 输入框下方一行工具开关（联网/深度思考/文件），处于激活态时品牌色。
- 出现位置：右栏 360（FleetX、Flux）、左栏 300（工业中枢）、独立页（CueMe）。

### 4.13 空状态

- 一个线稿/3D 小图 + 一句正在做什么 + 一个主操作。不要写"暂无数据"四个字了事。
- 引导型空状态用 4.7 的步骤条，不要用长文案。

## 5. 图表选型

| 问题 | 图形 | 备注 |
|---|---|---|
| 现在多少 | 大数字 + 单位 | 不用图 |
| 怎么变的 | 折线 / 面积 | ≤4 系列，2px 线 |
| 构成 | 环形（≤5 段）或堆叠条 | 环形中心写合计 |
| 排名 | 横向条 + 名次 | 条长归一化，右端值 |
| 分布 | 柱状 / 直方图 | 长尾很短的才用柱 |
| 占比达标 | 半环仪表 | 仅 0–100 |
| 相关性/流向 | 桑基 | 只在员工调动这类强关系场景 |
| 时间热力 | 格子热图 | 考勤、日历 |
| 实时脉冲 | 迷你柱列 | 每 2–5s 刷新，只做形状 |

统一规则：无 3D 图表、无阴影、无渐变填充（面积除外）、图例靠形状和位置而非只靠颜色。

## 6. Lumen：环境驱动的自适应主题

> 拖动顶部圆窗里的太阳 → 整个界面从午夜蓝连续过渡到正午白，中间经停金色时刻。
> 截图状态：`Midnight · 00:43` / `Golden hour · 07:01` / `High noon · 12:00`；默认 2 秒自动播放下一帧。

### 6.1 架构：一个状态 → 一套变量

```
sunX  ∈ [0,1]            ← 唯一可交互状态（拖动 / 自动播放）
  ↓ 映射
time  ∈ [0,24)           ← 语义标签 Midnight / Dawn / Golden hour / High noon / Dusk
  ↓ 计算（三组 colorStop 之间插值）
--bg --surface --ink --ink-2 --stroke --accent --chart-1 --warmth
```

- **组件里不写任何 `isNight ? ... : ...`**。所有颜色读 `--*`，主题切换只改根节点变量。
- 变量在浏览器里用 `color-mix()` 或 JS 线性插值算一次，然后写回 `style.setProperty`；不要每个元素各自算。
- 过渡用 `transition: background-color .6s cubic-bezier(.4,0,.2,1)`，拖动时关掉过渡（`data-dragging`）。
- 数值、图表数据**不随主题变**——变的是光和材质，不是事实。

### 6.2 关键色阶（可从截图取到的三点）

| 变量 | Night 00:43 | Golden hour 07:01 | High noon 12:00 |
|---|---|---|---|
| `--bg` | `#0B0D14` | `#B9A79E`（暖灰） | `#ECEBE7` |
| `--surface` | `rgba(24,27,38,.72)` | `rgba(40,32,30,.55)` | `#FFFFFF` |
| `--ink` | `#E7E9F0` | `#1A1512` | `#141518` |
| `--accent` | `#6E7BFF` | `#F0A04B` | `#E0A020` |
| 图表柱 | 蓝紫 | 琥珀 | 橙金 |

- 中间状态全部由这三个锚点插值，不手工调中间色。
- 卡片在暖光段变成"烟熏玻璃"（低不透明度 + 强描边），在正午段变成"实白卡"。这个变化由 `--warmth` 一个标量驱动 `background` 与 `backdrop-filter` 的强度即可。

### 6.3 配套的展示组件

- **圆形天空窗**：上沿半圆角的大窗，内部天空渐变、山线、太阳/月亮精灵、一根可拖的指针；窗外框是"舷窗"金属边。
- **状态标签**贴在窗下：`{时段名} · {HH:MM}`，12px。
- **四联指标**：`Sun elevation / Lux at desk / Colour temp / Daylight`。这是"主题的仪表盘"——把环境参数本身变成内容，而不是只做背景。
- **全天曲线**：`Light over a day`，钟形曲线 + 当前时刻竖线 + 指示点，柱子按当前色温染色。
- **活动流**：`Sunrise / Nightfall` 事件行，带 `now` 时间戳和 `live` 绿点。

### 6.4 落地要点

1. 交互入口必须**一眼可拖动**：指针是 `grab`，端点是 24px 圆点，窗内有微弱提示。
2. 键盘可用：`←/→` 调时间 1 小时，`Home/End` 到 0/24。
3. `prefers-reduced-motion` 下关闭自动播放与过渡，仅保留瞬时切换。
4. 主题变化时同步 `meta[name=theme-color]`，并给根节点 `data-theme="night|dawn|day|dusk"` 供外部查询。
5. 不要把它做成"用户设置里的深色模式开关"——那样就退化成两套主题。它的价值在**连续**。

## 7. 反模式（语料里真实出现的）

- **KPI 卡里塞迷你图成了装饰**：图与数值无关、也不随数据变，只是占位。要么真画，要么删。
- **纯黑底 + 高饱和霓虹**：长时间盯屏疲劳。底色提到 `#05080F` 级，霓虹只留品牌与告警两色。
- **一屏五六种语义色**：颜色一旦不唯一，就失去信息量。
- **玻璃层叠玻璃**：三个模糊层相叠，文字可读性崩塌，滚动掉帧。玻璃只做一层。
- **中文大标题用英文式字重 300**：在 Windows 上显得虚。中文正文用 400。
- **数字不用等宽**：刷新时数值左右抖动。
- **表格行高 < 44**：密集数据表可以 40，常规业务表 48 起。
- **未上线功能用可点击样式**：降不透明度 + 标注，不要骗点击。
